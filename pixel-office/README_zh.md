# Pixel Office for Windows

当前版本：`0.3.3+codex.20260820`。本仓库只支持 Windows 10 / Windows 11。

完整中文安装、更新、使用、安全与开发说明请查看：

- [GitHub 项目主页](https://github.com/WangJin991016/pixel-office-win#readme)
- [本插件英文说明](README.md)
- [Windows 开发文档](docs/DEVELOPMENT.md)

快速安装：

```powershell
codex plugin marketplace add WangJin991016/pixel-office-win --ref main
codex plugin add pixel-office@pixel-office-win
```

安装后完全重启 Codex Desktop，并新建一个任务。若右侧页面没有自动打开，请访问 <http://127.0.0.1:8791/>。

本项目不提供 macOS 或 Linux 安装支持。
